# Apple「User Privacy and Data Use」開発者向け文書

## 所在

https://developer.apple.com/app-store/user-privacy-and-data-use/ （2026-08-10 実読・到達確認済み）。
Apple Developer サイトの App Store セクション。ATT（AppTrackingTransparency）における
「トラッキング」の定義、許可が必要になる条件、対象外の条件を列挙する。

**未確認**: この文書には版の日付・改訂履歴の表記が無い。過去の版との差分を追うには
Wayback Machine 等が要る（執筆環境から到達できず未確認）。引用するときは参照日を添える。

## 誰が出したか（利害）

発行者は Apple。**この文書は仕様の言明であり、certainty は `attested`**——ATT が何を要求するかの
記述は、Apple 自身に不利な方向（開発者の離反・広告事業への批判）にも働く事実の言明で、
「その主張で儲かる」型の数字ではない。

ただし同じ Apple でも、自社広告（Apple Search Ads 等）の効果を語る文書は `vendor` になる。
発行元ではなく記述単位で層を判定する（docs/sources-directory.md）。

## 数字の取り方

数字は載っていない（仕様文書）。オプトイン率・広告費への影響などの定量は、この文書からは
取れない——それらは各計測ベンダーの vendor 数字か、各社決算の attested 数字で別途取る。
