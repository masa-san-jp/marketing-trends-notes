# 不安の多重化

## 何が変わったか

**不安を感じる人の割合は増えていない。増えているのは、一人が同時に抱える不安の種類の数である。**

内閣府「国民生活に関する世論調査」の時系列表を実読した（令和7年8月調査・2025年12月12日掲載）。

日常生活で悩みや不安を「感じている（小計）」の割合は、5回の調査でほぼ動いていない。

| 調査 | 該当者数 | 感じている（小計） |
|---|---|---|
| 令和3年9月 | 1,895 | 77.6％ |
| 令和4年10月 | 1,888 | 78.0％ |
| 令和5年11月 | 3,076 | 75.9％ |
| 令和6年8月 | 1,831 | 78.2％ |
| 令和7年8月 | 2,938 | 78.1％ |

一方、その内容（不安を感じていると答えた人への複数回答）の**計（M.T.）は 362.3 → 379.8 に増えている**。
一人あたりが挙げる不安の項目数が増えたということ。伸びは特定の領域に偏っている。

| 内容 | 令和3年9月 | 令和7年8月 | 差 |
|---|---|---|---|
| 現在の収入や資産について | 41.0％ | 47.9％ | **+6.9pt** |
| 今後の収入や資産の見通しについて | 55.0％ | 60.5％ | **+5.5pt** |
| 老後の生活設計について | 58.5％ | 63.9％ | **+5.4pt** |
| 自分の健康について | 60.8％ | 62.7％ | +1.9pt |
| 家族の健康について | 51.6％ | 51.2％ | -0.4pt |
| 近隣・地域との関係について | 7.5％ | 6.4％ | -1.1pt |
| 計（M.T.） | 362.3 | 379.8 | **+17.5pt** |

**増えたのは金銭に関する3項目**（現在の収入・今後の見通し・老後）で、健康は横ばい、人間関係と
地域はむしろ減っている。「不安が高まっている」という言い方は、この数字では**総量としては支持されず、
構成としては支持される**。

**未確認**: 令和3年より前の推移。実読した時系列表がこの5回分しか持っていない。同調査は昭和期から
続いているので、より長い系列を持つ表があるかは未確認。

**未確認**: 「今の気分」をSNSの速度で捉える独立した指標。この調査は年1回で、調査時点も年により
8月〜12月とばらつく。**日単位・週単位の気分の変動をこの出典で語ることはできない。**

## kind と stage の判定

**kind: demand-shift とした。** 判定表を上から当てて、規制（1）でも技術（2）でもなく、名付けた者が
儲かる側でもない（3・出所は内閣府）。需要側の数字が独立した出典で動いている（4）に当たる。

**stage: growing とした。** M.T. が5回の調査で一貫して高い方向に動いており（362.3 → 379.8）、
判定表の growing の目安「独立した出典で数字が伸びている」を満たす。peak（一般紙・地上波が説明なしで
使う）ではない——**そもそもこの現象に流通している名前が無い**。「不安の多重化」は私が付けた記述的な
ラベルで、当事者も媒体も使っていない。

**この判定の弱いところ**: 5点の系列で、うち令和5年は該当者数が3,076と他の年（1,800台）と大きく違う。
標本の取り方が年で変わっている可能性があり、**変化の一部が調査設計の差である可能性を排除できていない**。
調査票と標本抽出方法を読むまで、この trend の stage は暫定。

## 反証（これが偽なら何が観測されるか）

- 「一人あたりの不安が増えている」が偽なら、**次回調査で M.T. が 362 前後まで戻る**はず
  （predictions に置いた。令和8年調査で判定できる）
- 「金銭に偏っている」が偽なら、**健康・人間関係の項目も同程度に伸びている**はず——実測では
  健康 +1.9pt、地域 -1.1pt で、偏りは観測された
- 変化の正体が調査設計の差なら、**該当者数が同水準の年どうし（令和3年1,895 と令和6年1,831）で
  M.T. に差が出ない**はず。実測では 362.3 → 375.6 で差が出ており、設計差だけでは説明しにくい。
  ただしこれは排除の一歩目で、標本抽出方法の実読には至っていない
